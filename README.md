# NomadEXP
NomadEXP is a file explorer which is faster and better than default windows file explorer


# Currently in development
As of now only a terminal based searching feature has been added so far

# How to compile?
Save the main.c file in a folder and open terminal to that folder. Make sure you have GCC to compile the code.
```bash
gcc main.c -o nomadEXP.exe -O3 -Wall -Wextra -lkernel32
```
After the compilation, run the .exe as an adminstrator (CRUCIAL STEP)
